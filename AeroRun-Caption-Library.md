# AeroRun: Caption Library

Every caption in the 30-day campaign, ready to copy. Independent fictional concept, not an official Nike ad.

**House rules**
- First line = the hook. Instagram truncates after about 125 characters, so the point comes first.
- Max **5 hashtags** (Instagram's current cap), at the end of the caption.
- Creator posts carry **#ad** (ASCI disclosure) in the caption, not only the Paid-partnership tag.
- Text in [square brackets] is filled in only with real details, such as a real customer handle or a real review used with permission.
- Say "AeroRun", never "Nike AeroRun", in public copy.
